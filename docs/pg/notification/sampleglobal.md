# Sample Notification - Global

## OpenAPI Specification

```yaml
openapi: 3.0.1
info:
  title: ''
  description: ''
  version: 1.0.0
paths:
  /merchants-url/receive-notification:
    post:
      summary: Sample Notification - Global
      deprecated: false
      description: >-
        After setting up your Notification URL, we will send the notification
        for certain events such as when the payment is succeed, failed, and etc.


        Here is the sample notification that DOKU will send to merchant's
        server.
      tags:
        - Notification
      parameters:
        - name: Authorization
          in: header
          description: The user is API Key provided by DOKU
          required: true
          example: Base64(doku_ak_test_qblFNYngBkEdjEZ16jxxoWSM)
          schema:
            type: string
        - name: Client-Id
          in: header
          description: Unique merchant client identity that reproduce by DOKU
          required: true
          example: BRN-001-0000001
          schema:
            type: string
        - name: Request-Timestamp
          in: header
          description: Timestamp request on UTC time in ISO8601 UTC+0 format
          required: true
          example: '{{$date.isoTimestamp}}'
          schema:
            type: string
        - name: Signature
          in: header
          description: >-
            Conditional headers for specific request to DOKU such a PayOut,
            Refund or any of immediate transaction. To calculate the signature
            please see signature section. This headers also required when DOKU
            webhook call to merchant, and recommended for merchant to verified
          required: false
          example: ''
          schema:
            type: string
        - name: API-Version
          in: header
          description: >-
            This API Versioning will help manage changes and ensure backward
            compatibility, merchant must specify the desired API version in
            their requests.
          required: true
          example: doku-global.2025-12-01
          schema:
            type: string
      requestBody:
        content:
          application/json:
            schema:
              type: object
              properties:
                id:
                  $ref: '#/components/schemas/reference_id'
                order:
                  type: object
                  properties:
                    amount:
                      type: number
                      description: Amount format with or without decimal
                      format: float
                      title: ''
                      examples:
                        - 100.05
                    invoice_number:
                      type: string
                      description: >-
                        Generated by merchant to identify the order. **Notes**:
                        If you have Credit Card channel activated, the maximum
                        length is ```30``` chars due to the acquirer's
                        requirements
                      examples:
                        - INV-20210231-0001
                    currency:
                      type: string
                      description: 3 alphabetic currency code ISO 4217
                      maxLength: 3
                      minLength: 3
                      examples:
                        - MYR
                        - IDR
                    expired_at:
                      type: string
                      description: 'Expiry in UTC format. eg: 2029-08-05T12:00:00Z'
                  required:
                    - amount
                    - invoice_number
                    - currency
                    - expired_at
                  x-apidog-orders:
                    - amount
                    - invoice_number
                    - currency
                    - expired_at
                  x-apidog-ignore-properties: []
                payment:
                  type: object
                  properties:
                    channel:
                      type: string
                      enum:
                        - CREDIT_CARD
                        - INTERNET_BANKING_FPX
                        - EWALLET_TNG
                        - EWALLET_SHOPEEPAY
                        - EWALLET_GRABPAY
                    type:
                      type: string
                      description: Payment type, usually useable for Card payment
                      enum:
                        - SALE
                        - MOTO
                        - RECURRING
                        - INSTALLMENT
                        - AUTHORIZE
                      default: SALE
                    initiation_type:
                      type: string
                      description: >-
                        Usefull for channel CC to differentiate card submit by
                        customer or merchant to DOKU system
                      enum:
                        - merchant_initiate
                        - customer_initiate
                      default: customer_initiate
                      examples:
                        - customer_initiate
                    amount:
                      type: number
                      description: >-
                        Payment amount that paid by customer

                        for type authorize in the beginning it might represent
                        the authorized amount and at the end change to the total
                        captured amount
                      format: float
                      examples:
                        - 100.05
                    currency:
                      type: string
                      description: Processing transaction currency of client_id
                      minLength: 3
                      maxLength: 3
                      examples:
                        - MYR
                        - IDR
                    status:
                      $ref: '#/components/schemas/status'
                    state:
                      type: string
                      enum:
                        - INITIATE
                        - AUTHORIZED
                        - COMPLETED
                        - WAITING_APPROVAL
                        - WAITING_VERIFICATION
                      examples:
                        - COMPLETED
                    business_model:
                      type: string
                      enum:
                        - B2C
                        - B2B
                      description: Required for payment method FPX
                    bank_code:
                      type: string
                      description: Required for payment method FPX
                  required:
                    - channel
                    - amount
                    - currency
                    - status
                  x-apidog-orders:
                    - channel
                    - type
                    - initiation_type
                    - amount
                    - currency
                    - status
                    - state
                    - business_model
                    - bank_code
                  x-apidog-ignore-properties: []
                customer:
                  type: object
                  properties:
                    id:
                      type: string
                      description: >-
                        Unique customer identifier generated by merchant.
                        Mandatory if merchant wants to use tokenization feature.
                      maxLength: 50
                      examples:
                        - cust-001
                    name:
                      type: string
                      maxLength: 100
                      description: Customer name
                      examples:
                        - John Doe
                    email:
                      type: string
                      description: Customer email
                      examples:
                        - john@doku.com
                      maxLength: 128
                    phone:
                      type: string
                      description: Customer's phone number in international format (E.164)
                      maxLength: 16
                      examples:
                        - '+6281122334455'
                      pattern: ^\+[1-9]\d{1,14}$
                    country:
                      type: string
                      description: >-
                        Two-letter ISO 3166-1 alpha-2 country code of customer's
                        residence
                      maxLength: 2
                      minLength: 2
                      examples:
                        - ID
                        - MY
                    address:
                      type: string
                      description: Customer's primary address
                      maxLength: 400
                      examples:
                        - Street 6
                  x-apidog-orders:
                    - id
                    - name
                    - email
                    - phone
                    - country
                    - address
                  required:
                    - name
                    - email
                    - phone
                  x-apidog-ignore-properties: []
                metadata:
                  $ref: '#/components/schemas/metadata'
              required:
                - id
                - order
                - payment
              x-apidog-orders:
                - id
                - order
                - payment
                - customer
                - metadata
              x-apidog-ignore-properties: []
            example:
              id: 8fdC56eo-cC99-46E1-B6AC-4asD8755B25C
              order:
                amount: 100.05
                invoice_number: INV-20210231-0001
                currency: MYR
                expired_at: '2026-01-16T04:20:42.115Z'
              payment:
                channel: EWALLET_SHOPEEPAY
                type: SALE
                initiation_type: customer_initiate
                amount: 100.05
                currency: MYR
                status: SUCCESS
                state: COMPLETED
              customer:
                id: DOKU-CUST-001
                name: John Doe
                email: customer_email@test.com
                phone: '+60812345678'
                country: MY
                address: Street 1
              metadata:
                sample_key: your value
      responses:
        '200':
          description: ''
          headers: {}
          x-apidog-name: OK
      security: []
      x-apidog-folder: Notification
      x-apidog-status: released
      x-run-in-apidog: https://app.apidog.com/web/project/1033353/apis/api-42667319-run
components:
  schemas:
    metadata:
      type: object
      properties:
        sample_key:
          type: string
          examples:
            - your value
      description: >-
        You can use this parameter to attach key-value data for each request
        objects to DOKU and will return back on response.

        The limit is up to 100 keys, with key names up to 40 characters long and
        values up to 512 characters long.

        in the future this metadata will be able to show on your report, or even
        to used for filter the report
      required:
        - sample_key
      x-apidog-orders:
        - sample_key
      x-apidog-ignore-properties: []
      x-apidog-folder: ''
    status:
      type: string
      description: status of object, please refer to this section "Status & State"
      enum:
        - SUCCESS
        - PENDING
        - FAILED
        - EXPIRED
        - AUTHORIZED
        - CAPTURED
      x-apidog-folder: ''
    reference_id:
      type: string
      description: Unique identifier from merchant for the object.
      pattern: ^[A-Za-z0-9-_:]
      minLength: 1
      maxLength: 128
      examples:
        - 8fdC56eo-cC99-46E1-B6AC-4asD8755B25C
      x-apidog-folder: ''
  securitySchemes:
    bearerAuth:
      type: jwt
      scheme: bearer
      bearerFormat: JWT
servers: []
security: []
```
