# Postman Collection

### Why Use It?

A ready‑made Postman Collection lets you explore every DOKU endpoint in minutes—no copy‑pasting, no guesswork.
1. Try before you code: Fire real requests from Postman to understand payloads and responses.
2. One‑click setup: Environments, variables, and example tests are pre‑configured.
3. Shareable: Hand the same collection to teammates or vendors and guarantee everyone hits the API the same way.

### Import into Postman

1. Copy the DOKU API Collection link
2. Open your Postman and find Import button on the top left section
![image.png](https://api.apidog.com/api/v1/projects/1033353/resources/361105/image-preview)
4. Put the Link on the field, and click Continue Button
5. You will be asked to confirm, click the Import button

Now you should see DOKU API Collection on the left sidebar. Congratulations, you've just imported our Postman Collection.
